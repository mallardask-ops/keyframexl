## 1. BMS — база, обов'язкова

### 1.1 Характер (4 тести будь-якого рішення)

1. Справний стан мовчить. Знак — лише тому, що потребує уваги.
2. Інтерфейс не бреше. Порожній степ-патерн не видаємо за нотний. «Невідомо» — словом.
3. Наступна дія очевидна. Одна червона кнопка на екран (Play/Rec).
4. Рухається лише змінене. Плейхед + метри. Ніяких баунсів/паралаксу.

Правила кольору для DAW (адаптація кіту):
- Червоний `brand` — тільки Rec + головна дія. Playing — НЕ червоний, а білий кадр + форма.
- Постійний колір всередині сітки дозволений (mute/solo/arm/playing), але завжди дубль формою/літерою (M/S/R, заповнення vs контур).
- Зелений — тільки результат щойно запущеної дії. Постійні «все добре» крапки заборонені.
- Контраст тримати ≥4.5 для тексту. Слабке місце кіту `on_brand/brand_top` 4.2 — текст primary тільки 500 + ≥14px.

### 1.4 Розміри / радіуси / відступи

- Кнопка: 34px висота (Qt), транспортні — квадратні 34×34 з tooltip + aria-label. Хіт-таргет сітки ≥24px (тач 32), транспорт ≥44.
- Рядок таблиці 40, журнал 32, шапка 32, рядок меню 38, рядок вибору 48.
- Радіуси: кнопка/поле 7, повзунок 6, доріжка 8, панель/діалог/тост 10, прогрес 5, чекбокс 4. Пілюль немає.
- Сторінка: ліворуч 24 / праворуч 20. Між панелями 12, всередині 16. Між кнопками 8–10. Заголовок/таблиця/кнопки — на одній лівій/правій лінії.
- Каркас: мін 900×620, старт 1280×820. Сайдбар 200 (164 якщо вікно <1020). Панель деталей 320.

Для степ-секвенсера (адаптація щільності кіту):
- Транспорт і дії — 34/36 за кітом. Сітка — ряди 24–28, зазор 2–4 (не 12), хедер такту 24–28 (не 32).
- Клітинка степу — r4 (як чекбокс) або r6 (як повзунок), не 7/10. Зовнішні панелі — r10 лишити.
- Тінь з 6 шарів і градієнт на кожній з сотень клітинок — просадка в egui. Тінь тільки: зовнішня панель, діалог, тост. Клітинки: плоска заливка + 1px лінія.

### 1.5 Глибина: світло завжди зверху, тільки 2 глибини

Випукле (кнопка, активна вкладка, панель): 1.5px `edge` + нижній край 2px + градієнт `ctl_top→ctl_bottom` + світлий верх 1px `hi`.
Втоплене (доріжка, поле, журнал, disabled): `sunken` + 1.5px `edge` (поле 2px `input_line`) + внутрішня тінь 1px `low` зверху.
Натискання: миттєво, без анімації — край зникає, лице −2px, градієнт перевертається.

### 1.6 Рух

Hover 120мс, фокус 120мс, повзунок вкладок 200мс ease-out, зміна сторінки 120+200, тост/діалог 150–160 виїзд 8–10px, прогрес 400, пульс 1400 (тільки мінливий стан). Плейхед/метри — без easing, прямий малюнок по кадру. `reduced-motion` прибирає осідання/пульс, але не зупиняє плейхед.

### 1.7 Стани екрана (5 обов'язкових)

Дані / завантаження (короткий текст на місці даних, без скелетів) / порожньо (одне речення + кнопка наступної дії) / помилка (що сталось + що робити, біля поля) / частково (що вдалось + що не перевірено, тон `wait`).

### 1.8 Доступність

AA, колір ніколи не єдиний сигнал, все з клавіатури, порядок фокуса = порядок на екрані. Фокус: 1.5px `focus` (= `text`) + зазор 2, і лише після навігації з клавіатури (Tab), як `State_KeyboardFocusChange` у кіті. Іконкова кнопка — завжди tooltip + доступна назва. Обидві теми обов'язкові.

### 1.9 Текст українською

Коротко: стан + наступний крок. Без «!» і подяк («Збережено», не «успішно!»). Помилка не звинувачує. Словник: Хаб, Брокер, Не в мережі, Перезавантажити. Дата `2026-11-05`, час журналу `14:03:21`.

### 1.10 Чого не робимо (з кіту, дослівно)

Кольорові плашки зі статусом, світіння, неон; зелені крапки «все добре»; смужка зліва в заокругленому рядку; панель у панелі; сітка однакових карток з цифрами; декоративні шрифти; бібліотеки іконок; іконка на кожній кнопці; вигадані дані; системний `confirm()`; перемальований логотип; оцінка балами моделей замість очей на скріншотах.

## 2. Teenage Engineering — вайб, адаптований під BMS dark

Беремо логіку і графіку, НЕ залізо. Не копіюємо: OLED-шрифти 9px, приховані shift-комбінації, криптичні іконки без тексту, шурупи/ремінці, обмеження голосів як фічу, мініатюризацію TX-6.

### 2.1 Принципи TE для KeyFrameXL

1. Щільність + великі функціональні групи. BEAT 1–4 як 4 модулі-плити, всередині 01–16. Ніяких плаваючих тулбарів між ними.
2. Моноширинні підписи ВЕРХНІМ РЕГІСТРОМ з трекінгом 0.12–0.18em, 10–12px: `BEAT 1`, `STEP 07`, `VELOCITY`. Prose так не писати.
3. Мінімум хрому. Плоскі панелі, 1px seam-лінії між модулями. Без blur-тінeй і скляморфізму.
4. Один hero-акцент (червоний Play/Rec) + одна кодувальна палітра для 4 бітів (тонка смужка 2–3px, не заливка).
5. Колір = адреса, не статус. BEAT 1 червоний / 2 бурштин / 3 зелений / 4 синій — тільки точка/смужка.
6. Фізичність без скевоморфізму: верхній хайлайт 1px, активний степ — втоплений + світіння, груповий лейбл — «гравіювання» (текст на тон темніше + 1px нижній хайлайт).
7. Мікро-легенди deadpan: статусбар `KFXL v0.4 · CH 01 · 16 STEPS · PWR ●`, серійник `SN KFXL-133`, dot-matrix сіточка-вентиляція між групами.
8. Ніяких модалок. Mute/solo/step — один клік, 80–100мс, без пружин.
9. Модуль = міні-прилад: свій індикатор, свій clear/fill, свій патерн.
10. Чесність матеріалів: показувати шви 1px, нумерацію `01–16 tabular-nums`, юніти `dB/ms/%` моноширинним поруч зі значенням.

### 2.2 Шість прийомів під BMS dark (робити саме так)

1. Гравійовані лейбли `● BEAT 1 — KICK`: моно 11px uppercase, `secondary`, зверху смужка 2px кольору групи.
2. Нумерація `01–16 tabular-nums`: під степом 10px mono secondary; активний — білий + акцентна точка.
3. Апаратна Play: один прямокутник r8, `brand_fill`, білий моно `▶ PLAY`, hover darken 100мс, без градієнта. Stop/Clear — нейтральні з top-highlight.
4. Шви без шурупів: outer bezel 1px hi зверху + dark знизу, модулі — 1px seam.
5. Втоплений дисплей патерну (TP-7 стрічка): recessed `sunken`, бурштиновий/зелений фосфор моно 13px, faint scanlines alpha 0.03, тонка червона лінія плейхеда.
6. Punch-in ряд як EP-133: 8–12 низьких педів `FX 01–12`, press-down спрацьовує, release відпадає. Правий клік = автоматизація, без модалок.

## 3. FL Studio — канон, який мусить бути

### Channel Rack
Рядок = канал (будь-який: семплер чи барабанний голос) + кроки з групуванням 4-4-4-4 (довгий патерн — більше лотків, скрол убік). Крок = нота довжиною 1/16 на C5. Канал, чиї ноти зійшли з сітки кроків, показує прев'ю нот замість падів, клік відкриває Piano roll (FL). LED mute (LMB) / solo (RMB), `Ctrl+1..0`. Swing-knob + Graph Editor velocity. Селектор патерну в Toolbar, не в Rack. `F6` — Rack.

### Piano Roll
Сітка час/пітч, нота = прямокутник. Ghost notes `Alt+V` (суцільні — цей патерн, контурні — перекриття в Playlist). Snap Main/Line/Cell/None + `Alt` тимчасово off + `Ctrl+Q` quantize. Zoom X/Y окремо (`PgUp/PgDn`, `Ctrl+RMB` до селекції). Velocity lane внизу, `Shift+Enter` сховати. Slide `S` / portamento `O`. Інструменти `P/D/T/C/Z/E`. `Right-Click` = видалити завжди, `Right-drag` = пачка. `Left-drag` на ноті = move, краї = resize. `F7` — Roll.

### Playlist
Кліп = прямокутник з ім'ям + кольором. Копія = shared data (правка в Roll міняє всі копії). Make Unique з меню кліпа + `Ctrl+Shift+V` + `Shift+V+drag`. `Double-Click` = Roll, `Alt+Double-Click` = Rack. `F5` — Playlist.

### Transport
`Space` Play/Stop (з ревіндом), `Ctrl+Space` Play/Pause (без), `R` Record, `L` PAT/SONG, `Ctrl+M` метроном. Дисплей `Bar:Step:Tick` (PPQ 96) + BPM з tap. Numpad `+/-` ±1 BPM.

### Глобальне
Undo `Ctrl+Z / Ctrl+Shift+Z` скрізь. Focus ring на активному редакторі. Шорткати `F5/F6/F7/F8`, однолітерні тільки коли typing-keys вимкнено. Хіт-таргет ≥24px. Статусбар-хінт з шорткатом в hover.

### Вікна (гібрид: док + плаваючі)
- Кожен редактор — вкладка (`Tab::Playlist | Rack | Roll{instrument}`). Вкладку тягнуть: у центр листа — стає вкладкою, до краю — поділ, за межі доку — плаваюче вікно. Правий клік по вкладці: Float / Dock.
- Piano roll — окремий на кожен інструмент; кілька одночасно. Клік по семплеру в Browser відкриває/фокусує його roll, правий клік — у плаваючому вікні.
- F5/F6/F7 як у FL: закрите — відкрити на звичному місці; відкрите, але не у фокусі — сфокусувати; у фокусі — закрити. Roll стає вкладкою поруч з іншим Roll або з Rack, Rack — поруч з Roll, Playlist — поділом зверху.
- Пресети робочих просторів: **Arrange** (Playlist над Rack), **Compose** (Rack над Roll, Playlist вкладкою), **Edit** (великий Roll, під ним Rack + Playlist). Alt+1..3. Кожен пресет памʼятає власні зміни; Reset повертає його розкладку.
- Розкладка всіх пресетів зберігається в `~/.config/keyframexl/workspace.ron` (не частіше разу на секунду, тільки при зміні). RON, бо прямокутники доку до першого кадру нескінченні, а JSON їх не тримає.
- Усі вікна закриті — повідомлення в центрі + Restore layout.
- Редактор завжди вміщується у своє вікно: Rack прокручується, якщо вікно менше за вміст (педи не вужчі за 28px); Playlist прокручується вбік; Piano roll прокручує висоту нот усередині сітки (колесо; Ctrl+колесо — висота рядка 10–30px), лінійка і velocity лишаються на місці, velocity ховається у вікнах нижче 260px.
- Хром доку в термінах кіту: смуга вкладок `side`, активна вкладка `panel_top`, вкладка у фокусі `ctl_top`, шви `bg` 6px, тіло `panel_bottom` + край `edge`, оверлей скидання — `brand` 22%.

### Меню і дека
- **Головне меню** (`src/ui/menu.rs`, 26 px) — структура FL: FILE (New, Open, Save, Save as, Export → Wave/MIDI, Import, Exit), EDIT (Undo/Redo/Cut/Copy/Paste), ADD (Channel → Sampler / Drum voice, Effect, Plugin picker, Pattern), PATTERNS (Find next empty F4, Rename F2, Clone, Delete), VIEW (вікна F5–F9, Browser Alt+F8, Workspace, Close all F12, Interface size), OPTIONS, TOOLS (Tap, Panic Ctrl+H), HELP (Keyboard shortcuts F1). Кожен пункт із гарячою клавішею. Чого ще нема (мікшер, MIDI, запис, плагіни, виділення нот) — пункт є, але неактивний, з підказкою «Arrives with …», щоб структура й клавіші потім не зсувались. Праворуч — ім'я проєкту і `unsaved`.
- Save пише у відомий файл без діалогу; перший раз і Save as (Ctrl+Shift+S) питають шлях. Export — Ctrl+R. New — Ctrl+N. FILE → Open recent (10 останніх), Recover autosave.
- **Незбережене не губиться мовчки**: New, Open, відкриття проєкту перетягуванням і закриття вікна при незбережених змінах показують «Save changes to … before …?» — Save (Enter) / Don't save / Cancel (Esc). Заголовок вікна ОС: `Ім'я * — KeyFrameXL`.
- **Дека, ряд 1** (48 px): транспорт (Play, Stop, Record ● — R; сірий вимкнено, червоний увімкнено, з кільцем — пише), Pattern|Song, LCD, TEMPO, Tap. Файлові кнопки звідси прибрано — вони в FILE.
- **Дека, ряд 2** (34 px): кнопки вікон з лампою «відкрито» (Playlist F5, Rack F6, Roll F7, Mixer F9 — неактивна, Browser Alt+F8), глобальний Snap (piano roll читає його), селектор патерна `− [NN Name ▾] +` (+ на останньому створює новий), hint bar (як користуватись тим, що у фокусі), CPU аудіопотоку і кількість голосів. Компоненти ряду — `kit::tool_button` і `kit::dropdown` висотою `TOOL_H` 26.
- **Розмір інтерфейсу** — Ctrl+= / Ctrl+- / Ctrl+0 (egui zoom, 80–150 %), зберігається з розкладкою. Видимість Browser — теж.

### Deck
Play — єдина червона кнопка (Primary), іконка play/pause. Stop — нейтральна. `Pattern|Song` — сегментний контрол (втоплена доріжка + thumb). LCD — втоплений колодязь із семисегментними цифрами, привиди сегментів лишаються видимими (`lcd_off`), індикатор ходу — трикутник. Енкодери: TEMPO синій, SWING зелений (колір = адреса). Цифри BPM на LCD — теж контрол, як у FL: drag ↕ (0.2 BPM/px, Shift 0.02), колесо ±1 (Shift ±0.1), double-click — ввести число, ПКМ — 120; рамка при наведенні. Поведінка будь-якої ручки (`kit::knob`): drag ↕ — 200 px на весь хід, Shift у 10 разів точніше; колесо над ручкою — 1 % ходу на клац, сторінку при цьому не прокручує (ручка забирає колесо в ScrollArea); ↑/↓ у фокусі; double-click або Ctrl+click — скидання; ПКМ — Reset, Type in value (Enter застосовує, Esc скасовує, розуміє %, Hz/kHz, ms/s), Copy / Paste value, неактивні Create automation clip і Link to controller до появи автоматизації. Жест (drag, серія клаців колеса до 0.6 с, введене значення) — один крок undo. Лог-шкала (`log: true`) для часу й частоти.

### Channel rack
Розміри за FL (`research_notes/ui-gap-research.md` §1.4): ряд 30 px, пад 22 px заввишки і 22–34 px завширшки (зайва ширина лишається порожньою, пади не розтягуються), лотки по 4 кроки з проміжком 10. Над падами ряд LED: білий = поточний крок. Пад: вимкнений — нейтральна опукла клавіша; увімкнений — `brand`, смужка velocity 2 px унизу; номер кроку друкується лише на падах від 28 px. Голова ряду (230 px), як у FL: лампа (зелена = грає, синя = solo; клік — mute, ПКМ або Ctrl+клік — solo), міні-ручки Pan (біла) і Vol (помаранчева) 18 px з тією самою поведінкою, що й великі ручки, коробка мікшера (`M` = Master до появи мікшера), кнопка з назвою (клік — вікно інструмента, ПКМ — Piano roll, Load preset, Delete). Заголовок вікна: ▾ меню (Add channel, Unmute all, Clear pattern, Detach, Close), праворуч кількість кроків і SWING (зелений) — свінг живе в Rack, як Global swing у FL. Канал з нотами поза сіткою кроків — прев'ю нот на всю ширину лотків, клік відкриває Piano roll.

### Заголовки вікон
Кожне вікно починається з `App::panel_header`: кнопка ▾ (меню вікна, FL arrow menu), caps-контекст, інструменти праворуч, шов. Меню закінчується `window_menu_tail`: Detach (float) або Dock, Close. Чого ще нема — пункт неактивний з поясненням. Глобальний Snap — у ряду 2 деки і в ▾ → Snap піано-рола; окремих чипів snap у вікнах нема.

### Piano roll
Клавіатура справжня (білі `key_white`, чорні 62% ширини), підписи C. Лінійка з бітами `1 / 1.2 / 1.3 / 1.4`, плейхед — білий трикутник у лінійці + лінія 1.5px. Ноти — опуклі `brand`, тьмяніші при меншій velocity; ноти інших інструментів — контурні привиди. Слайди — `wait` контур + трикутник + траєкторія. Курсор показує дію: Grab на тілі, ResizeHorizontal біля правого краю. Velocity lane — «льодяники» на початках нот. Шапка: Draw P / Slide S, Snap 1/32 · 1/16 · 1/8T · 1/4 · Bar · Off (вигляд, не дані: ноти тримають будь-який тік, Alt обходить snap), енкодер VELOCITY білий. Позиції в статусі — `такт.біт.крок +тіки`.
Оновлено в етапі C: клавіатура 48 px, лінійка 24 px, нижня панель 88 px (Velocity / Pan / Release / Fine / Mod X / Mod Y — вибір у ▾ → Target control). Зум X від курсора (ширина клітинки 4–160 px, Ctrl+колесо або щипок), зум Y (ряд 8–30 px, Alt+колесо), Shift+колесо — горизонтальний скрол. Захоплення краю ноти — 7 px з обох боків, курсор показує ресайз. За кінцем патерна сітка затінена. Клік по клавішах і нова нота звучать; клік по лінійці — перемотка. Інструменти (список у шапці, ▾ → Tool, клавіші FL): Draw P · Paint B · Delete D · Mute T · Slice C · Select E · Zoom Z · Slide S; курсор показує дію інструмента. Слайд редагується тим самим жестом, що й нота: тіло — рух (час і ціль), краї — довжина. Porta-нота має білий скіс на початку (▾ → Tools → Porta on / off, Porta for new notes). Колір ноти — ▾ → Note color (червоний за замовчуванням, синій, зелений, жовтий, помаранчевий, білий).

### Playlist
Треки вниз, такти вбік; голова треку 120 px з лампою mute та ім'ям, ряд 32 px; лінійка — клік/протяжка перемотує (Song). Drag — привид цілі, double-click — Piano roll, правий клік — меню (Open in rack/roll, Make unique, Delete). Порожньо: одне речення + кнопка наступної дії. Кліп — прямокутник рівно на свій час: лівий край = початок, правий = кінець, без відступів і «капсул» (радіус 2 px), висота ряду мінус 2 px. Зверху смуга 13 px кольору патерна з ▾ (намальований трикутник, не гліф) і назвою, `×N` якщо дані спільні; нижче — прев'ю нот у справжньому часі. Кліп довший за патерн повторює його (як у FL), межі повторів — тонкі риски. Ставиться будь-де: Snap Off або Alt — точний тік.

### Mixer
Вікно F9, за замовчуванням плаваюче на ~94 % ширини. Ряд смуг прокручується вбік, інспектор праворуч завжди видно. Смуга 64 px з проміжком 4: номер і ● arm праворуч від нього (сірий — ні, червоний — озброєна, яскраво-червоний — пише), ім'я, лампа (клік — mute, Ctrl+клік/ПКМ — solo, синя при solo), pan (біла) · sep (зелена) поруч, фейдер у дБ (−60…+6, double-click — 0 дБ) з метром, кнопка маршруту в Master. Master — перша смуга, ширша рамка. Праворуч інспектор 320 px вибраної вставки: ім'я, «From:» (канали, що в неї грають), 10 слотів ефектів (LED увімк., Mix, вибір ефекту, ×), ручки параметрів вибраного слота (Parametric EQ 2 — таблиця: ряд на смугу, Freq синя · Gain помаранчева · Q біла), STRIP EQ (Low/Mid/High ±18 дБ), посили (лише на вставки з більшим номером — так петель не буває). Канал Rack обирає вставку коробкою з номером (клік — список, колесо — сусідня); Ctrl+L у Rack — виділені канали на вільні вставки.

### Browser → Files
Вкладки `Project | Files` над деревом. Files: ряд «Add folder · Refresh», ряд «SORT [Name ▾]» (Name / Type / Newest / Largest, теки зверху), рядок дерева 24 px; пошук унизу шукає по всіх підтеках у фоні й пише прогрес над списком; теки згортаються, видно тільки те, що програма відкриває (wav flac ogg dwp kfxl). Клік по семплу — прослуховування (повторний клік або Esc — стоп), double-click — у вибраний семплер або новий канал; перетягування на канал Rack/вікно інструмента — туди, на порожнє місце Rack — новий канал. Кореневі теки додаються «+», зберігаються.

### Status
Тон явний (`Tone::Quiet/Done/Wait/Bad`), не вгадується з тексту. Зелений — тільки результат щойно запущеної дії (Saved, Exported, Imported). `Wait` пульсує 1.4с. Статус показує лише результати дій; підказка поточного виду живе в ряду 2 деки. Довгий текст обрізається «…» перед правою легендою (`48 KHZ · PPQ 480 · KFXL`) і ніколи її не перекриває; повний текст — у hover.

## 5. Компоненти (`src/ui/kit.rs`) — тільки ними малювати

| Функція | Що це | Правило |
|---|---|---|
| `raised` / `control` | опукла форма: край 1.5 + губа 2 + градієнт + `hi` | натиснено — губа зникає, градієнт перевернуто |
| `sunken` | колодязь | найтемніше на сторінці, внутрішня тінь `low` |
| `panel` | зовнішній блок | тінь 6 кроків, r10, губа 1 |
| `thumb` | поточний пункт/вкладка | губа 1 |
| `button` / `button_sized` | Primary / Normal / Ghost | 34px, disabled = втоплено + `faint` |
| `chips` | сегментний вибір | thumb їде 200мс |
| `knob` | енкодер TE | дуга 270°, колір = адреса |
| `seg_text` | LCD-цифри | привиди сегментів видно |
| `led` | індикатор | без світіння |
| `caps` | гравійований підпис | моно uppercase, трекінг 0.12em, 10–11px |

Кольори й шрифти — тільки з `src/theme.rs`. Хардкод `Color32::from_*` поза темою заборонено.

## 6. Definition of Done (FL-канон, стан 2026-11-14)

Готово: 16 кроків 4×4 + LED плейхеда; M/S + Ctrl+1..3; Pattern/Song + L; Swing; Draw/Slide P/S; Snap + Alt; ghost notes; velocity lane; move/resize; Make unique трьома шляхами (кнопка, меню кліпа, Del для видалення); F5/F6/F7; Space / Ctrl+Space; Ctrl+Z/Shift+Z/Y; Ctrl+S/O; tap tempo; хінти в статусі.
Готово також: док + плаваючі вікна, кілька Piano roll, пресети робочих просторів, збереження й скидання розкладки, скрол і zoom висоти нот.
Відкрито: zoom X (довші патерни), Ctrl+Q quantize, Graph editor, мітки патернів (rename/recolor), light-тема, метроном/REC (потрібне аудіо), українська локалізація інтерфейсу (рішення за власником).
