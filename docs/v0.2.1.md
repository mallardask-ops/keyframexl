# KeyFrameXL 0.2.1 — план (підтримка Windows + нативний PipeWire)

Ціль релізу: повноцінна нативна підтримка **OS Windows (x86_64)** без «урізаних»
режимів (WASAPI + ASIO, вбудовані інструменти й ефекти, VST3/CLAP/VST2 з
вбудованими HWND-редакторами, ізольований міст плагінів, самооновлення та
нічні/стабільні збірки), а також перехід на **cpal 0.18** з нативним PipeWire
на Linux і статичним MP3-енкодером.

Оскільки фізичної Windows-машини для розробки поки немає, основна перевірка
збірки та автотестів іде через **`windows-latest` у GitHub Actions CI** з
першого етапу (`W0`), з максимальним покриттям автотестами для кожного
Windows-шару (IPC, оновлювач, платформенні утиліти, HWND-вікна).

Статус: ☐ не почато · ◐ в роботі · ☑ готово.

---

## Порядок робіт

1. **W0 (фундамент):** ребейз E1 (`cpal 0.18` / PipeWire) → `cfg`-гігієна →
   `windows-test` у CI (`clippy` + усі тести на `windows-latest`).
2. **W1 (базовий DAW на Windows):** `src/platform/` (тема, локаль, шрифти,
   `open_path`, логи, бібліотеки FL), статичний LAME (MP3), аудіо WASAPI
   Shared/Exclusive + ASIO, іконка `.exe` та `windows_subsystem`.
3. **W2 (оновлювач і пакування):** `.zip` + `.old.exe` самооновлення у
   `src/updater.rs`, джоби `windows-x86_64` у `nightly.yml` і `release.yml`,
   user-scope інсталятор.
4. **W3 (хостинг плагінів на Windows):** розбиття `src/plugins.rs`,
   `libloading` у `vst2.rs` / `clap.rs`, стандартні папки плагінів Windows,
   `editor_win32.rs` (`HWND`, `SetWindowRgn`, DPI Per-Monitor v2, фокус),
   підключення `WinEmbed` із `vendor/vst3-host`.
5. **W4 (міст плагінів на Windows):** `src/bridge/ipc/` на Named Pipes +
   `CreateFileMappingW` + `CreateEventW` + `CREATE_NO_WINDOW` + Job Object;
   прогін `bridge::tests` на `windows-latest`.
6. **W5 (сумісність і фінальний поліш):** кросплатформні проєкти `.kfxl`
   (шляхи + матчинг плагінів за ID/назвою), пошук семплів FL Studio на Windows,
   документація/посібник (EN/UK), вичитка українського UI, перевірка на
   реальній Windows (коли з'явиться доступ).

- [x] Розділити залежності у `Cargo.toml` за таргетами (`eframe` x11/wayland,

  фіча `asio` для Windows).
- [x] Додати кросплатформні бекенди в `src/audio.rs` (`Wasapi`, `Asio`) і
  `#[cfg]`-розгалуження в `src/mp3.rs`, `src/main.rs`, `src/flp.rs`,
  `src/updater.rs`.
- [x] Створити `src/platform/` із чистими заглушками `stubs.rs` для не-Linux
  модулів (`fl_link`, `fl_native`, `flp_freeze`, тимчасово `plugins`/`bridge`
  до W3/W4), щоб `src/ui/` компілювався й тестувався на Windows без `cfg`-хаосу.
- [x] Додати джобу `windows-test` (`windows-latest`) у `.github/workflows/ci.yml`
  (`cargo clippy --all-targets -- -D warnings`, `cargo test --lib`,

  `dir.sync_all` у `project_io.rs`/`bundle.rs` та CRLF у `shortcuts.rs`).

### W1 — Платформний шар, аудіо WASAPI/ASIO, статичний MP3 [обов'язково] ☑
- `src/platform/{linux,windows}.rs`:
  - `open_path` / `open_url` замість 6 викликів `xdg-open`.
  - Системна тема: `AppsUseLightTheme` із реєстру Windows замість `gdbus`.
  - Системна локаль: `GetUserDefaultLocaleName` (`uk-UA` → Українська).
  - Шрифт із каною (Vocal): `%WINDIR%\Fonts\{YuGothM.ttc,meiryo.ttc,msgothic.ttc}`.
  - Логи: `dirs::data_local_dir()` + перенаправлення stderr, `ExitProcess(0)`.
  - Бібліотеки: пошук `C:\Program Files\Image-Line\FL Studio *\Data\Patches\Packs`
    та `dirs::audio_dir()`.
- Статично зібраний LAME для експорту MP3 (`src/mp3.rs`) на Linux і Windows
  без системного пакета `libmp3lame`.
- Аудіо на Windows (`src/audio.rs`, `src/settings.rs`, `src/ui/settings_ui.rs`):
  - **WASAPI** (Shared і Exclusive) + **ASIO** (`cpal/asio` через `asio-sys` +
    вибір хоста/драйвера в *Settings → Audio* + атрибуція торгової марки
    Steinberg ASIO у README/About).
  - Приховати Linux-опції (*X11*, *Wine*, *DXVK*, *FL Link*) на Windows.
- Вікно та `.exe`: `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]`
  + `AttachConsole` для CLI-підкоманд; вбудована `.ico`-іконка через `winresource`
  у `build.rs`.
- Demo Mode (`src/ui/show.rs`): запуск `ffmpeg` із `CREATE_NO_WINDOW`.

### W2 — Самооновлювач і пакування Windows [обов'язково] ☐
- `src/updater.rs`: вибір активу за таргетом (`keyframexl-windows-x86_64.zip` +
  `.sha256`), розпакування через крейт `zip`, перевірка PE-заголовка (`MZ`),
  заміна працюючого `.exe` через перейменування в `.old.exe` і прибирання на
  наступному старті; автотести на `windows-latest`.
- `.github/workflows/nightly.yml` і `release.yml`: збірка й публікація
  `keyframexl-windows-x86_64.zip` + `.sha256` поруч із Linux-архівом.
- User-scope інсталятор (Inno Setup у `%LOCALAPPDATA%\Programs\KeyFrameXL`,
  без прав адміністратора, з асоціацією `.kfxl` та ярликом у Start Menu).

### W3 — Нативний хостинг плагінів на Windows (VST3, CLAP, VST2) [обов'язково] ☐
- Розбити монолітний `src/plugins.rs` на `plugins/{mod,scan,host,wine,editor_x11,editor_win32}.rs`.
- Замінити `parent: Option<u32>` на кросплатформний `NativeWindow` (`X11`/`Win32`)
  і витягати `RawWindowHandle::Win32` у `src/ui/mod.rs`.
- Перевести `src/vst2.rs` і `src/clap.rs` із `libc::dlopen` на `libloading`.
- Стандартні папки Windows: `%COMMONPROGRAMFILES%\{VST3,CLAP}`,
  `%LOCALAPPDATA%\Programs\Common\{VST3,CLAP}`, `Steinberg\VstPlugins`,
  `VstPlugins`, `Image-Line\FL Studio *\Plugins\VST`; розширення `.dll` для VST2.
- `editor_win32.rs`:
  - `WinEmbed` із `vendor/vst3-host` для VST3 (із `set_editor_scale_factor`).
  - CLAP `"win32"` GUI + таймери без `posix-fd-support`.
  - VST2 `effEditOpen(hwnd)` + `effEditIdle` + `audioMasterSizeWindow`.
  - Дочірнє `HWND` (`WS_CHILD | WS_CLIPCHILDREN`), кліпінг `SetWindowRgn` під
    попапи egui, DPI Per-Monitor v2, пересилання хоткеїв DAW при фокусі плагіна.

### W4 — Ізольований міст плагінів (`src/bridge`) на Windows [обов'язково] ☐
- Абстрагувати `src/bridge/ipc/{linux,windows}.rs`:

  - Іменований auto-reset `CreateEventW` замість `futex`.
  - Named Pipe (`\\.\pipe\kfxl-...`) замість `UnixStream`.
  - `CREATE_NO_WINDOW` + Windows Job Object (`JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`).
- Увімкнути всі тести `src/bridge/tests.rs` у CI на `windows-latest`.
