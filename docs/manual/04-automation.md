# Automation and controllers

## Automation clips

Any knob, fader or plugin parameter can change over the song.

1. Move the control you want to automate.
2. *Tools → Last tweaked → Create automation clip* adds a clip for it on
   the playlist.
3. Open the clip and drag its points. The small handle between two
   points bends the curve: drag it up or down.

Automation clips play in song mode. After a clip ends the control goes
back to its own value, so keep the clip as long as the change should last.

Recording (`R`, then play) also records the knobs you move into
automation clips.

## Knobs

- Drag up and down to change a value; hold `Shift` for fine steps.
- Double-click resets to the default.
- Right-click to type a value, copy it, or paste one.

## MIDI controllers

- *Tools → Last tweaked → Link to controller…*: move a knob or slider on
  your controller, and it controls that parameter.
- *Tools → Multilink to controllers* (`Ctrl+J`): switch it on, move
  several on-screen controls, then the hardware controls in the same order.
- `Ctrl+T` turns the computer keyboard into a piano for the active channel.

See *Audio, MIDI and recording* for MIDI input and clock.
