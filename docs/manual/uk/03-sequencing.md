# Патерни, канали й плейліст

## Патерни

Патерн містить ноти для будь-якої кількості каналів. Дека показує поточний
патерн: прокрутіть над ним колесо, щоб перемкнути, подвійний клік (або
`F2`) перейменовує. Меню *Патерни* додає (`Ctrl+Shift+Ins`), знаходить
наступний порожній (`F4`), клонує, фарбує й видаляє патерни. Останній
патерн видалити не можна.

**Режим патерна** грає поточний патерн по колу. **Режим пісні** грає
плейліст. `L` перемикає між ними.

## Стелаж каналів (F6)

Кожне джерело звуку — канал: семплер, синтезатор Tide, звук Forge, вокал
або плагін.

- Кроки: клік — увімкнути, ще клік — вимкнути, `Shift+клік` — швидкість,
  ПКМ — очистити. Канал, ноти якого не є простими кроками, показує їх як
  маленьке прев'ю піано-ролу.
- Ліворуч від кожного рядка: лампа глушіння (клік глушить, ПКМ або
  `Ctrl+клік` вмикає соло), ручки панорами й гучності та інсерт мікшера,
  у який грає канал (клік — вибрати, `Ctrl+колесо` — крокувати). Клік по
  назві каналу відкриває його вікно; ПКМ — більше дій.
- Канали вибирають смужкою на правому кінці кожного рядка (`Ctrl`
  перемикає, `Shift` розширює). `Alt+↑` / `Alt+↓` пересувають їх, `Alt+C`
  клонує разом із нотами, `Alt+Delete` видаляє.
- `Ctrl+L` спрямовує вибрані канали в перші вільні інсерти мікшера.
- `Ctrl+K` відкриває графік швидкостей під кроками.
- `Ctrl+1 … 0` глушить канали 1–10, `Ctrl+Shift+1 … 0` вмикає їм соло.
- *Додати → Набір барабанів* додає цілий вбудований набір одразу.

## Піано-рол (F7)

Піано-рол редагує ноти одного каналу в поточному патерні.

Інструменти: `P` олівець, `B` пензель (малює під час перетягування),
`D` видалення, `T` глушіння, `C` розрізання, `E` виділення, `Z` масштаб,
`S` слайд (нота, що ковзає в наступну).

- Прив'язка — на панелі інструментів (1/16, 1/4, такт…). Утримуйте `Alt`
  під час перетягування, щоб її ігнорувати.
- `Ctrl+A` виділяє все, `Ctrl+D` знімає виділення; тягніть по порожньому
  місцю, щоб виділити рамкою.
- Стрілки рухають виділене: `↑` / `↓` на півтон, `Ctrl+↑` / `Ctrl+↓` на
  октаву, `←` / `→` на крок сітки, `Alt+←` / `Alt+→` на один тік.
  `Shift+←` / `Shift+→` змінюють довжину.
- `Ctrl+C`, `Ctrl+X`, `Ctrl+V` копіюють, вирізають і вставляють;
  `Ctrl+B` дублює виділене одразу після нього.
- `Ctrl+Q` квантує, `Alt+Q` відкриває діалог квантування. `Ctrl+L` робить
  ноти легато, `Ctrl+U` нарізає, `Ctrl+G` склеює.
- `Alt+V` показує ноти інших каналів як тіньові ноти.
- Смуга під нотами редагує швидкість та інші властивості нот.
- На вокальному каналі `F2` редагує склад вибраної ноти.

## Генератор рифів (Alt+E)

*Інструменти → Генератор рифів* пише риф для активного каналу. Він працює у
вісім етапів, перелічених ліворуч: Прогресія, Акорди, Арпеджіо, Дзеркало,
Рівні, Артикуляція, Грув і Припасування. Кожен етап має власні елементи
керування (тональність і лад, голоси акорду, ритм, свінг, діапазон нот…)
і його можна окремо скинути чи варіювати. *Рецепти* завантажують готове
налаштування. Прослуховування грає риф по колу; *Застосувати весь риф*
пише ноти в патерн, а `Ctrl+Z` це скасовує.

## Плейліст (F5)

Плейліст розставляє кліпи на доріжках. Кліп — це патерн, аудіофайл або
крива автоматизації.

- Виберіть патерн і клацніть на доріжці, щоб поставити його. Тягніть
  кліпи, щоб пересунути, тягніть їхній правий край, щоб укоротити чи
  подовжити.
- Перетягування ПКМ виділяє кліпи рамкою; короткий клік ПКМ видаляє кліп
  під курсором. `Ctrl+A` виділяє все, `Esc` знімає виділення, `Delete`
  видаляє виділене.
- Перетягніть аудіофайл із браузера на доріжку, щоб створити аудіокліп.
- Клік по лінійці пересуває курсор відтворення. Перетягування по лінійці
  створює часове виділення, яке пісня повторює; подвійний клік по лінійці
  його знімає.
- **Маркери** називають частини пісні: ПКМ по лінійці додає маркер.
  `Ctrl+Alt+←` / `Ctrl+Alt+→` переходять між ними; подвійний клік по
  маркеру (або *Петля до наступного маркера* в його меню) зациклює цей
  фрагмент.
- **Доріжка темпу** вгорі змінює темп упродовж пісні.

## Скасування

Майже кожну зміну можна скасувати: `Ctrl+Z` скасовує, `Ctrl+Y` або
`Ctrl+Shift+Z` повторює.
